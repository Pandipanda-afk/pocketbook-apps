Quick guide

Installer une application

En quelques étapes simples, depuis votre ordinateur.

01 — DOWNLOAD

Téléchargez le fichier

Obtenez le fichier .app de l'application que vous souhaitez installer.

02 — TRANSFER

Copiez sur la liseuse

Connectez la liseuse en USB et copiez le fichier dans le dossier applications à la racine du stockage.

03 — LAUNCH

Déconnectez & lancez

Éjectez proprement votre appareil. L'application devrait apparaître dans le menu Applications.
